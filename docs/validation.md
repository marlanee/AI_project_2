# 검증 범위와 결과

## 실행 기록

2026-10-23 전체 로컬 제출본 66개 자동 테스트가 통과했다. 공개본은 교육 원본과 로컬 모델을 사용하는 추가 UI 검사를 구분하고 CI의 키 없는 단위·계약 검사를 별도로 실행한다. 이 저장소의 최신 public_tests.xml과 GitHub Actions 결과를 따른다. 테스트 통과는 모든 답변의 사실 정확성을 의미하지 않는다.

실제 AI와 공개 웹 검증은 2026-10-21 기록이다. 6질문·RAG 사용/미사용 12응답, 후속 질문·근거 부족 보류·문서 주입 거절·NASA PDF 인용을 확인했다. 2026-10-23에는 실제 UI에서 확인 불가·인용 없음·영화별 대화 분리·자연어 조건 탐색·검색 비교·저장 평가를 확인했다. 공개 참고 기록은 public_data/evaluation.json에 있으며 원본 줄거리만 사실 요약으로 교체했다는 표식을 유지했다.

## 실험과 해석

동일 인터스텔라 문서는 청크 1000/200에서 9개, 600/100에서 18개였다. 외부 Top-k 2/5는 메타데이터 포함 3/6건이었다. MMR의 문서 다양성 증가는 정답률 향상과 다른 지표다.

전후 비교 Q1에서 시간여행 이용 사례의 서술을 웜홀 관측 전체로 확대하는 문제가 있었다. 실제 서비스 사실 확인 지침에서는 확대해석을 금지했고 별도 통합 응답에서 확인 불가로 보류함을 확인했다. Q3에서는 영화 소개로 역사 인물 실존을 뒷받침하는 약한 인용이 있었다. Q4에서는 원문의 함대 숫자가 다른 자료와 달라 원문 정확성·시점·기준 자체가 별도 검토 대상임을 기록했다. Q6은 양쪽 모두 보류했으므로 RAG만의 개선이라고 주장하지 않는다.

## 성능과 한계

로컬 모델 적재 최대 약 674MiB는 무료 서버 512MB 한도를 넘었다. 공개용 원격 임베딩·사전 계산 캐시를 분리한 뒤 과거 공개 실측은 약 227.6MiB였다. 측정 시점·방법이 다르므로 정밀한 감소율이나 지속 최대값을 제시하지 않는다.

공개 실제 질문 약 50.5초/28.8초, 이번 로컬 실제 질문 12.81초/5.678초 기록이 있다. 무료 서버 첫 기동 사용성은 개선 과제다. 사용자 수·정확도 향상률·시간 절감률·유료 운영 성과는 측정하지 않았다.

공개본의 실제 키 없는 회귀 검사: 2026-10-23, 63 passed / 0 failed. public_tests.xml에 보존했다.
